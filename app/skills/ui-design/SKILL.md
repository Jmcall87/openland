# UI design

Use Tailwind CSS utility classes. Prefer shadcn/ui component patterns (Button, Card, Dialog, Input, Tabs).
- Mobile-first responsive breakpoints (sm/md/lg).
- Accessible: labels on inputs, focus rings, aria attributes, contrast ≥ 4.5:1.
- Spacing: 4/8px grid. Typography: clear hierarchy, readable line length.
- Dark mode: use CSS variables or Tailwind dark: variants.
- Never invent fake data in demos — use realistic placeholders.
